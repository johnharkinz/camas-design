# camas-design

Design source of truth for camas.dev and the Camas tools.

This repository contains the briefs, references, explorations, decisions and
eventually a runnable reference site used to design:

- camas.dev
- Shareable
- Noggin
- Bonce

It is not currently a shared production component library.

See [docs/project-brief.md](docs/project-brief.md) for the current brief and
[docs/decisions/](docs/decisions/) for agreed design decisions.
