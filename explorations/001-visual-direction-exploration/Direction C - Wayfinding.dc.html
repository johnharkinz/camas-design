WAY­FINDING
Camas as a station map. Each tool gets a line colour and a round sign; the system tells you where you are and where to go next, loudly and unambiguously.
Why it fits
Tools are about getting a clear answer fast. Signage is the most trusted clarity language there is — public, legible, unfussy.
Distinctive
Wide heavy grotesk, flat line colours, circle badges, thick rules. A family of tools becomes a colour-coded network that can grow.
Works well
camas.dev and status: a verdict reads from across the room. Tool colours make each product instantly identifiable in the toolbar and Web Store.
May struggle
Volume. Inside tools the colour must be held back to a header band or it overwhelms. Wide type eats horizontal space in a 360px popup.
Scaling
Good if disciplined: expanded type only above 20px; body set at normal width. The line colour shrinks to a header band and a badge at extension size.

Overlapping circles = the collection; each circle = one line. Every tool gets a letter disc in its line colour — the same disc is the extension icon, the favicon and the Web Store tile. New tools join by taking a new hue at the same lightness.
TYPE

One family, Archivo, two widths. Expanded black for signs and verdicts; normal width for everything you read or type.
COLOUR
Line colours share one lightness and chroma, so black text always passes. Status uses shape first: ● pass, ▲ warn, ■ fail.
SHAPE & DENSITY
Pills and circles only. 3px rules for structure, 1px for rows. Big, clear targets; 44px controls on web.
