ROUND 2 — DEVELOPING A
Index, with character
Still a catalogue — but now a reference book with a voice. Camas gets its character from the conventions of well-made reference works: the dictionary entry, the running head, the thumb index and the hanging numeral.
WHAT CHANGED FROM A, AND WHY
1A dictionary entry as identity. “camas, n.” with two numbered senses — the Gaelic word for a bay, and the index. It explains the name, gives the brand a dry, specific voice and costs no decoration.
2Thumb index. The stepped edge tabs of a reference book become navigation: tools on the site, sections in Shareable, views in the popup. One ownable device, used everywhere.
3Numbers became the icons. Each tool’s mark is its index number in an ink square. Future tools get the next number — the family grows without inventing new symbols.
4Weight contrast for rhythm. Light 300 hanging numerals against 800 names, so the page has a beat. Colour is unchanged; the red mark still means “here”.
5Findings are written as entries. Plain-English headword first, then the technical detail set below it like a citation.
Still a risk: it depends on writing. If copy turns generic, the system goes back to being merely tidy.
