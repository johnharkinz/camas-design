# References

This folder contains design references used to inform the Camas design project.

References can include:

- screenshots
- links
- examples of typography
- layout ideas
- interaction patterns
- branding examples
- product UI examples
- browser-extension UI examples

A reference should capture **why it is useful**, not just what it is.

Where possible, add a short note explaining what is worth paying attention to, for example:

- strong information hierarchy
- good use of whitespace
- compact controls
- clear status communication
- distinctive but restrained branding
- effective typography
- useful browser-extension layout

References are inspiration, not specifications.

Do not assume that a referenced design should be copied directly or that every part of it is desirable.
